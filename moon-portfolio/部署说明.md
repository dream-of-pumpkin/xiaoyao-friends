# 部署上线指南

项目是纯静态站点（HTML + CSS + JS），没有后端，任何静态托管都能用。

---

## 第一步：打包

```bash
cd moon-portfolio
npm install
npm run build
```

打包后产物在 **`dist/`** 目录，里面就是最终要上传的网站文件。
本地可以先预览确认：

```bash
npm run preview     # → http://localhost:4173
```

---

## 方式一：Vercel（推荐，5 分钟上线）

**最省事**，自动识别 Vite 项目，还能绑定自己的域名。

### 用命令行

```bash
npm install -g vercel
cd moon-portfolio
vercel              # 第一次会让你登录、确认项目
```

部署完会给你一个 `https://xxx.vercel.app` 链接。

### 用网页（不用装工具）

1. 打开 [vercel.com](https://vercel.com)，用 GitHub 登录
2. 点 **Add New → Project**
3. 导入你的 GitHub 仓库
4. Framework Preset 选 **Vite**（会自动识别）
5. Build Command 填 `npm run build`，Output Directory 填 `dist`
6. 点 **Deploy**

### 绑自己的域名

Vercel 后台 → **Settings → Domains** → 添加域名，按提示改 DNS（CNAME 记录）即可。

---

## 方式二：Netlify

1. 打开 [app.netlify.com](https://app.netlify.com)，登录
2. 拖拽 **`dist` 文件夹**到页面上传区域
3. 几秒后就上线了，拿到 `https://xxx.netlify.app`

**或者**用 GitHub 方式：

1. **Add new site → Import an existing project**
2. 选你的仓库
3. Build command 填 `npm run build`
4. Publish directory 填 `dist`

---

## 方式三：GitHub Pages（免费且不用额外账号）

### 1. 改配置

`vite.config.js` 里已经有 `base: './'`，这正是 Pages 需要的（相对路径）。
如果你想用 `用户名.github.io/仓库名/` 这种子路径形式，把 `base` 改成：

```js
base: '/仓库名/',
```

### 2. 加工作流

在仓库里新建 `.github/workflows/deploy.yml`：

```yaml
name: Deploy
on:
  push:
    branches: [main]
jobs:
  build-deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npm ci
      - run: npm run build
      - uses: actions/upload-pages-artifact@v3
        with:
          path: dist
      - uses: actions/deploy-pages@v4
        id: deployment
```

### 3. 开启 Pages

仓库 **Settings → Pages → Source** 选 **GitHub Actions**，保存。

之后每次 `git push` 都会自动重新部署，网址是
`https://用户名.github.io/仓库名/`。

## 方式四：腾讯云 / 阿里云等国内静态托管

国内访问更快，但需要备案域名。

1. 买服务器或用对象存储（COS / OSS）
2. 把 `dist/` 里的文件全部上传到存储桶根目录
3. 在存储桶控制台开启「静态网站托管」，把 `index.html` 设为索引文档
4. 绑定已备案的域名，配置 CDN 加速

注意：**`base` 要改成 `/`**（域名根路径），而不是 `./`。

---

## 注意事项

### 1. 字体已经本地化了

`public/assets/fonts/` 里有 683 个 woff2 分片，**已经打包进 dist**。
所以国内访问也不需要翻墙加载 Google Fonts，不会有字体闪一下再变黑体的问题。

### 2. 如果要换域名

`vite.config.js` 的 `base` 决定资源引用路径：

| 部署位置 | `base` 值 |
|---|---|
| 域名根目录（vercel.app / netlify.app） | `'./'` ✅ 已经是这个 |
| GitHub Pages 子路径 | `'/仓库名/'` |
| 对象存储子目录 | `'/子目录/'` |

改完记得重新 `npm run build`。

### 3. 体积

整个 `dist/` 大约 **1.5 MB**（主要是字体分片），gzip 后传输量更小，加载很快。

如果想再小，可以只保留实际用到的字体分片，或者把中文字体换成系统字体兜底。

### 4. 内容更新

改完源码后：

```bash
npm run build
```

然后把新的 `dist/` 重新部署即可。Vercel / Netlify / GitHub Pages 配好 CI 之后，直接 `git push` 就自动更新了。

---

## 一句话总结

```bash
npm install && npm run build
# 然后把 dist/ 拖到任何静态托管上，或者
npx vercel --prod
```
